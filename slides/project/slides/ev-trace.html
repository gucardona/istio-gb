Uma requisição, três serviços, seis spans

Os sidecars criam os spans. A aplicação só repassa os cabeçalhos de trace.

inventory 1,9 ms · catalog 18,4 ms · frontend 24,6 ms: dá para ver quanto cada salto soma.

O tracing é a única função que pede algo da aplicação: repassar x-request-id, traceparent e os cabeçalhos b3. O resto é do Envoy. O span do load aparece deslocado por diferença de relógio entre os nós.
