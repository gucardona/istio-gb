METODOLOGIA DE TESTES: INFRAESTRUTURA

Kubernetes na Azure, montado por scripts

1

Criar o cluster

Três máquinas na Azure e um registro para guardar a imagem da aplicação.

2

Instalar o Istio

Com a configuração padrão, mais as ferramentas de monitoramento.

3

Gerar a imagem

Compilamos o Go e enviamos uma imagem mínima para o registro.

4

Publicar os três casos

Um comando aplica os arquivos de configuração de cada caso.

5

Rodar os testes

Scripts disparam as cargas e guardam os resultados.

6

Desligar tudo

Um último script apaga o cluster para não gastar crédito.

AMBIENTE

AKS com 3 máquinas de 2 vCPU (sistema, aplicação e carga), Kubernetes 1.36 e Istio 1.26

Para qualquer pessoa conseguir repetir o experimento, deixamos tudo em scripts. O aks-up.sh cria o cluster com três nós (um para o sistema, um para a aplicação e um só para o gerador de carga) e o registro de imagens. O istio-install.sh instala o Istio 1.26 com o perfil padrão e as ferramentas de monitoramento. O build-image.sh compila o programa e envia uma imagem mínima para o registro. Com kubectl apply publicamos os três casos. Os scripts da pasta bench rodam os testes e salvam os resultados. E o aks-down.sh apaga tudo no final.
